# Personal Financial Agent

## Project hypothesis
We believe students can make better financial decisions when an agent
can access their connected financial accounts and provide personalized
budgeting guidance.

## Assumptions
- This depends on complete, up-to-date financial data. Eventually, the
  application should check account connections daily and flag
  disconnected accounts or stale data.
- A successful connection does not guarantee that every account is
  included or that the data is current.

## Evaluation approach
We will evaluate the idea by asking students to compare their spending
and budgeting experience during their first month using the agent with
the preceding three months managing finances themselves. This is an
initial evaluation approach, not proof that the agent caused any
improvement.
